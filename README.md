# 沪教版数学四年级下册｜知识卡片复习

面向四年级下册期末复习的单页静态网站，适合 iPad、手机和电脑使用。

## 功能

- 按单元逐张复习知识卡片
- 展开答案后进行即时小测验
- 标记已掌握并显示整体进度
- 使用浏览器 LocalStorage 在本设备保存学习记录
- 响应式移动端界面

## 在线发布

仓库为公开仓库。请在 GitHub 仓库的 **Settings → Pages** 中选择：

- **Build and deployment**：`Deploy from a branch`
- **Branch**：`main`
- **Folder**：`/ (root)`

保存后，页面地址为：

`https://jayceeli.github.io/JOYEE-math-4/`

## 本地使用

直接用浏览器打开 `index.html` 即可，无需安装或后端服务。
